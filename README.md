# SISTEMA-OS-ESTOQUE
Central Integrada da **Jamaica Artefatos de Borracha**: sistema web que unifica a gestão de **Ordens de Serviço (O.S.)** e o **Estoque de Peças** da manutenção. Permite abrir e acompanhar chamados, controlar retiradas, emitir alertas de estoque baixo e exportar relatórios em Excel com total agilidade e segurança.
